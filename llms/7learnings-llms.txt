# 7Learnings

> 7Learnings GmbH (Berlin and New York, founded 2019) builds a retail AI platform for
> predictive pricing. Machine-learning models forecast the sales, revenue and profit impact of
> every candidate price, and the platform pushes optimized price, promotion, performance-
> marketing and ordering decisions back into the retailer's commerce stack.

## Read this first: there is no public API

7Learnings publishes **no public REST API, no OpenAPI, no GraphQL schema and no AsyncAPI**.
Do not look for one, and do not assume an `api.7learnings.com` exists — that hostname resolves
only through a wildcard DNS record and presents no TLS certificate.

Integration is **batch data exchange**, contracted per customer:

- **In**: BigQuery, Snowflake, Microsoft Fabric (database tables); Google Cloud Storage,
  AWS S3, Azure Blob Storage, SFTP, FTPS, HTTPS (CSV or Parquet files); or vendor connectors —
  Tradebyte, Shopify, Google Shopping, Google Ads, Google Analytics, Amazon Selling Partner API,
  Amazon Ads.
- **Out**: optimized price and marketing changes as a BigQuery or Snowflake table, a CSV/Parquet
  file on GCS/S3/Azure Blob/SFTP/HTTPS, a Salesforce Commerce Cloud pricebook, or an API call
  into commercetools, Tradebyte, Plentymarkets, Shopify or Scayle Commerce Engine.

The export schema is customized per customer: "We always customize the data export format for
each customer, so that you can decide which KPIs should be in these export files."

## Agent surfaces

- **MCP**: `https://7learnings.com/wp-json/mcp/mcp-oauth-server` is a live, OAuth-protected MCP
  endpoint served from the company's own domain. `tools/list` returns
  `401 mcp_unauthorized` — the tool set requires an authenticated introspection and is not
  published. It is the WordPress MCP Adapter on the marketing site and knowledge base; nothing
  in 7Learnings' documentation presents it as an interface to the pricing platform.
  - Authorization server metadata: https://7learnings.com/.well-known/oauth-authorization-server
  - Protected resource metadata: https://7learnings.com/.well-known/oauth-protected-resource
  - OAuth 2.0 authorization_code + refresh_token, PKCE S256, one scope: `mcp`.
- **A2A agent card**: none. `/.well-known/agent-card.json` and `/.well-known/agent.json` both 404.
- **llms.txt**: 7Learnings does not publish one. This file was generated by API Evangelist from
  the company's public surface; it is not a first-party document.
